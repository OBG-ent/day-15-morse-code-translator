# · · · MORSE · · ·

A **morse code translator** that runs right in your browser — type a message, get dots and dashes. Translate morse back to text too, and *hear* it played as classic radio beeps.

## ✨ Features

- **Text → Morse** and **Morse → Text** — full alphabet, numbers, and punctuation
- **Live translation** — it auto-detects what you typed and converts as you type
- **▶ Play sound** — hear your message as real morse-code beeps (Web Audio API)
- **Copy button** — one tap to copy the translation
- Dark, radio-operator themed UI with a glowing green morse display

## 🚀 Run it in 30 seconds

No build step, no server. Just:

1. Download `index.html`
2. Double-click it (or drag it into any browser)
3. Type a message and hit **TO MORSE**

## 🧠 What you'll practice

- JavaScript object maps (and reversing one for decode)
- Regex-based auto-detection of input type
- The **Web Audio API** — scheduling oscillators with precise timing
- Clipboard API with a tiny "copied!" feedback touch
- Responsive dark-mode styling with pure CSS

## 📸 What you'll see

A dark card with a gold `··· MORSE ···` header, a big text box for your message, and a glowing-green morse output area. Buttons: **TO MORSE**, **TO TEXT**, **▶ PLAY SOUND**, **COPY**.
